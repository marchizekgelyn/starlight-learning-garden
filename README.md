# Starlight Learning Garden

A private family education website designed strictly for my daughters, with separate age-aware learning paths for an early learner and an elementary learner.

## Family-first rules

- No advertisements, analytics, trackers, or behavioral profiling.
- No public child profiles, names, photographs, chat, or messaging.
- No external links inside child-facing learning modes.
- Progress remains in the browser's local storage.
- Read-aloud uses the device's built-in speech synthesis.
- A parent chooses and adds future educational material.

## Learning paths

### Little Learner Meadow
Short supervised activities with large touch targets, one-step prompts, read-aloud support, and positive feedback for colors, counting, shapes, and first words.

### Explorer Observatory
Guided missions that introduce an idea, provide an interactive model, ask for evidence, and end with explanation or reflection.

## Content structure

Future lessons are organized by age path and subject. Larger applications such as ATLAS Math Academy and the Super Calculator belong in dedicated modules and remain separate from the toddler interface.

## Privacy boundary

Do not commit child names, birthdays, photographs, school details, location, health information, credentials, or identifying progress reports. This repository is intentionally private. GitHub Pages should remain disabled unless the parent deliberately chooses to publish a public learning URL.
