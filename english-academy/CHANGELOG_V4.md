# ATLAS English Academy v4 — release notes

- Preserved entire uploaded v3.0 website and its original v1/v2/v3 data, grading engine and artifacts.
- Added separate original 25.44 MiB reading and assignment corpus, with 64 case scenarios systematically adapted to 16 levels.
- Added 1,024 guided reading units with 3,072 paired texts, 10,240 exact-graded comprehension questions, 3,072 writing prompts, 9,920 worked instructional cards, 6,144 transfer prompts, glossaries, evidence maps and detailed source-linked rubrics.
- Introduced a complete new offline reading UI with level filters, grade-selective lazy loading, topic search, text-to-speech, readable print styles, quiz grading with answer explanations, writing autosave and parent review.
- Added four **separate** college-level independent-reading challenges with 20 keyed questions, four extended writing prompts, and immutable first-attempt history during normal UI use.
- Defined conservative internal mastery milestones, not a standardized college-level or reading-age certification.
- Built a cross-page handoff to the preserved v3 paper-correction lab with source text and prompt.
- Added static corpus audits, Chromium UI interaction tests, student privacy notes, course inventory, original content builder and regeneration instructions.
