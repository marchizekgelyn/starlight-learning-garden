# ATLAS English Academy — Development History

## 3.0 · Expanded paragraph and paper assessment

- Preserved v1 and v2 source material and the backwards-compatible browser progress schema.
- Added eight developmental source-linked writing tasks for every one of 1,536 v2 lessons (12,288 new writing assignments).
- Added grade-specific weighting and paragraph/page target guidance for preschool, kindergarten, grades 1–12 and two college levels.
- Added sentence segmentation, reference-concept group matching, evidence trace snippets, cautious negation mismatch warnings, repeated n-grams, extensive source copying warnings, and grade-aware explanatory feedback.
- Added deliberately broad estimated score ranges and refusal to present freeform papers as scored when no source/criteria exist.
- Improved optional local proofreading: conservative high-confidence spelling/spacing/capitalization fixes with student confirmation.
- Added paper assignment picker, rubric checklists, parent verification questions, independent adult scores, parent-score comparison stats and optional local-model excerpt-verified rubric feedback.
- Added 16 task-code files (>30 MiB), source generator, CSV index, synthetic regressions, browser smoke test, human-label evaluation tool and validation protocol.
- **No external teacher-reviewed sample data was supplied; numeric scoring accuracy has not been established.**

## 2.0 · Visual Curriculum + Writing Studio (retained)

Version 2.0's 1,536 new lessons, 23,040 exercises, SVG visual library, six interactive educational labs, rubric-style writing hints, paper studio and original v1 compatibility remain intact.

## 1.0 · Original Academy (retained)

Original 192 lessons and 1,920 assignments remain accessible through `source/classic.html`.
