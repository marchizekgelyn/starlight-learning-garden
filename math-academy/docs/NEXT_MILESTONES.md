# ATLAS Math Academy — Verified v2.0 Remaining Work

Version 2.0 is an expanded and operational static web foundation, not a full symbolic computer algebra system or a formally curriculum-accredited course platform.

1. Browser-driven end-to-end tests in an unrestricted browser/CI environment, including accessibility and responsive visual QA.
2. Review of all lessons against a named public standards framework, by grade and jurisdiction; version 2.0 is broad-coverage, not formally standards mapped.
3. Dedicated proof and conceptual reasoning modules beyond per-topic numeric worked examples.
4. Arbitrary precision rational arithmetic and optional symbolic algebra with advanced equation solving.
5. Extended indefinite integration, transformations, Laplace methods, differential equations and numerical ODE solvers.
6. 3D graphing, implicit curves, parametric visualization, inequalities and interactive geometric constructions.
7. A spaced-repetition scheduler and prerequisite-aware adaptive diagnostics with additional independently generated practice variations for each individual lesson.
8. Expanded financial tools: daily accrual with exact day-count conventions, variable rates, mortgage tax/escrow/insurance, balloon structures, fee-inclusive APR, inflation-linked contributions, cash-flow date parsing and multiple IRR detection.
9. Ability to import/export progress to a user-controlled file across browsers (currently export only) and local user profiles.
10. Content editorial review, diagrams reconciled precisely to every unique worked example, formal math typesetting, and screen-reader-tested accessible text diagrams.

The current release never claims that a numerical estimate is a rigorous proof, a lender-certified calculation, or a complete calculus textbook on every subtopic.
