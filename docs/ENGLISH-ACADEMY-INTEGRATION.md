# ATLAS English and Reading Academy integration

Starlight Learning Garden includes the complete ATLAS English & Reading Academy v4.0 under `/english-academy/`.

- Source archive: `ATLAS_English_Reading_Academy_v4.0_College_Level_Pathway_25MB_Content.zip`
- SHA-256: `824EDF195EE96BA5B603451AB8AF46555689BBE7899E90E58282F05602BB7FC9`
- Curriculum entry: `/english-academy/source/index.html`
- Direct reading pathway: `/english-academy/source/reading-pathway.html`
- Levels: Preschool, Kindergarten, Grades 1–12, College I, College II
- Included package: 1,658 files and 134,334,679 bytes

The package describes 1,024 guided units, 3,072 readings, 10,240 objective questions, 3,072 writing assignments, 9,920 instruction cards, four independent college transfer challenges, and 1,536 illustrations. These are patterned fictional educational cases, not independently researched real-world reports. Internal thresholds are practice milestones, not accredited placement, diagnosis, college credit, or proof of college readiness. Writing requires human review.

Student writing and progress remain browser-local. Exported progress JSON can contain private writing and should be stored carefully.
